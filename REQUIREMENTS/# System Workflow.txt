# System Workflow

1. Raspberry Pi boots.
2. Initialize camera services.
3. Initialize AI services.
4. Cameras enter idle/lightweight monitoring mode.
5. OpenCV performs motion detection.
6. If no movement is detected, remain idle.
7. If movement is detected, capture an image. (if there is a person face upclose then capture an image)
8. Run face detection.
9. If no face is found, capture again up to a defined limit. (500ms wait time, can be longer depends on system)
10. If a face is found, perform face recognition.
11. Generate face embedding.
12. Compare against registered users.
13. If matched, create attendance record.
14. If unknown, create unknown-face record.
15. Store required information in Firebase.
16. Dashboard updates.
17. Return camera to idle state.

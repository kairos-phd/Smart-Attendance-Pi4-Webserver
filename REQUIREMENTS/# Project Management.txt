# Project Management

## 1. Project Information

Project:
Smart Attendance System Using Raspberry Pi 4 and AI Face Recognition

Project type:
IoT / Edge Computing / Computer Vision / AI / Web Application

Team size:
2 students

Maximum project duration:
8 weeks

Primary hardware:
- Raspberry Pi 4 Model B 4GB
- 2 USB cameras / Raspberry Pi cameras
- MicroSD / SSD
- 5V 3A power supply
- WiFi / Ethernet

Primary objective:
Develop a functional smart attendance system capable of detecting
people, capturing images, detecting and recognizing faces, recording
attendance, synchronizing data, and providing a web dashboard.

Primary architecture:

Camera 1 ─┐
          ├──> Raspberry Pi 4 ──> AI / Backend ──> Firebase
Camera 2 ─┘                                      │
                                                  ↓
                                           Web Dashboard


## 2. Project Scope

### Core Scope

The core project must support:

- 2 cameras
- Raspberry Pi 4 4GB
- Lightweight motion detection
- Event-triggered image capture
- Face detection
- Face recognition
- Attendance recording
- Firebase/cloud database
- Web dashboard
- Wireless communication
- Basic system monitoring
- Basic error handling

### Optional Extensions

These should only be implemented if the core system is already stable:

- Third camera
- Advanced attendance statistics
- Excel/PDF export
- Liveness detection
- Notifications
- Remote device management
- Mobile application
- Multi-location deployment

Optional features must not compromise completion of the core system.


# 3. Development Strategy

Because the team consists of only two students, development must be
performed in parallel.

The project should not be developed as a completely sequential
pipeline.

Student 1 should primarily focus on:

- Raspberry Pi
- Camera
- Computer Vision
- AI
- System integration

Student 2 should primarily focus on:

- Backend
- Firebase
- Web Dashboard
- Wireless communication
- Database

Both students are responsible for:

- System architecture
- Testing
- Debugging
- Documentation
- Final integration

Both members should understand the complete system rather than
working as completely independent developers.

# 18. Risk Management

## Risk 1 — Raspberry Pi AI Performance

Problem:
Face recognition may be too slow on Raspberry Pi 4.

Mitigation:
Test AI during Week 4 and select an appropriate lightweight model.


## Risk 2 — Two Cameras Overload Raspberry Pi

Problem:
Two simultaneous cameras may consume excessive CPU, RAM or USB
bandwidth.

Mitigation:
Test two cameras early. Reduce resolution/FPS or modify the
processing pipeline if required.


## Risk 3 — AI Accuracy

Problem:
Recognition accuracy may be insufficient.

Mitigation:
Improve face registration images, preprocessing, lighting and
recognition threshold.


## Risk 4 — Network Failure

Problem:
WiFi or Internet connection is interrupted.

Mitigation:
Store important events locally and synchronize them when the
connection is restored.


## Risk 5 — Two-Person Workload

Problem:
A single component may take longer than expected and block the
entire project.

Mitigation:
Develop components in parallel and integrate continuously.


## Risk 6 — Scope Creep

Problem:
Additional features consume the limited 8-week schedule.

Mitigation:
MVP has priority. Optional features are only developed after
the complete core system is working.


# 19. Final Success Criteria

The project should be considered complete when:

1. Two cameras operate reliably.
2. Raspberry Pi can manage both cameras.
3. Motion triggers image capture.
4. Faces can be detected.
5. Registered users can be recognized.
6. Unknown faces can be identified as unknown.
7. Attendance is recorded with timestamp.
8. Data is stored correctly.
9. Web dashboard displays attendance data.
10. System communicates wirelessly.
11. Basic network failure handling works.
12. The complete system can operate continuously during a
    demonstration.
13. Technical documentation and presentation are complete.

The project should prioritize a reliable and demonstrable two-camera
system over additional features.

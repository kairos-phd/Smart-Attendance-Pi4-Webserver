# Hardware

## Main Processing

Raspberry Pi 4 Model B
RAM: 4GB

Role:
Edge computing, camera management, AI processing,
data processing and system control.

## Cameras

Quantity: 2

Preferred:
USB webcams such as Logitech C270/C310 or any webcam available

Alternative:
Raspberry Pi Camera Module

Role:
Image acquisition.

## Storage

MicroSD 16gb minimum

## Power

5V 3A USB-C Raspberry Pi power supply.

## Network (for web/app connecting)

WiFi or Gigabit Ethernet.

## Cooling

Raspberry Pi heatsink + fan.

## Optional

HDMI display for debugging or use Pi connect on PC to debug. (LCD Screen for displaying employee info)
